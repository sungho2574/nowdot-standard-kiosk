# 영상 파일 위치

이 폴더에 터치 영역별 영상을 아래 이름으로 넣어주세요.

- `1.mp4` — 터치 영역 1번
- `2.mp4` — 터치 영역 2번
- `3.mp4` — 터치 영역 3번
- `4.mp4` — 터치 영역 4번
- `5.mp4` — 터치 영역 5번

파일 이름이나 확장자를 바꾸고 싶다면 `app/src/config/touchAreas.js` 의 `video` 값을 함께 수정하면 됩니다.
(경로는 이 `public` 폴더가 기준이라 `/videos/1.mp4` 형태로 적습니다.)

코덱은 `H.264 + AAC` 의 `.mp4` 를 권장합니다.
